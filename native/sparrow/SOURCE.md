# Sparrow source provenance

Unmodified upstream source in `vendor/`: Sparrow v0.3.0, commit c5e64b3
(https://github.com/JeroenGar/sparrow/releases/tag/v0.3.0).
Upstream code is MIT licensed; the license is retained in `vendor/LICENSE`.
Only the library/bin source and Cargo manifest are copied; upstream benchmark
data, studio and binary artifacts are omitted.

The Animatus JSON-lines wrapper lives in `src/`. Dependencies are pinned in
`Cargo.lock`. The build packages dependency license notices and source locations,
including jagua-rs 1.0.0 (MPL-2.0), with the executable. The jagua-rs source is
unmodified and available from https://crates.io/crates/jagua-rs/1.0.0.
